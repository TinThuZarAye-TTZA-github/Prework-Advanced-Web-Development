# WEB103 Prework - *👉🏿Prework: Advanced Web Development (WEB103)*

Submitted by: **👉🏿 Tin Thu Zar Aye**

About this web app: **👉🏿Creator is a full-stack React web application that allows users to explore, add, view, edit, and delete content creators. The app uses React Router for navigation and Supabase as the backend database to store creator information, including their name, description, image, and social media links (YouTube, Twitter, and Instagram). Users can browse all creators, view detailed profiles, update existing information, and manage creators through an intuitive interface**

Time spent: **👉🏿 12** hours

## Notes

One of the biggest challenges while building this application was integrating React with Supabase for full CRUD functionality. I encountered issues with configuring the database, routing between pages, and correctly fetching, updating, and deleting creator data. I also spent time debugging state management and implementing a custom delete confirmation modal instead of using the default browser confirmation dialog. Overall, this project helped me gain a better understanding of React Router, React hooks, component-based design, and connecting a frontend application to a backend database using Supabase.
